# SX1278 (SX127x) Radio Model

Renode model: `peripherals/sx1278/SX1278.cs`
Class: `Antmicro.Renode.Peripherals.SPI.SX1278`
Short form in `.repl`: `SPI.SX1278`

A Semtech SX1276/77/78 sub-GHz radio, modeled as an SPI slave of the ESP32-C3
SPI2 (GP-SPI) master delivered in wave 1. This wave (wave 2) delivers the
**foundation**: register-accurate SPI access, `RegVersion`, and `RegOpMode`
mode/LoRa transitions — enough for the firmware's `SxReset` / `SxReg` /
`SxStatus` / `identify()` to work in emulation. The RF data path is deferred.

## Attaching in a `.repl`

The SPI2 master is a `NullRegistrationPointPeripheralContainer<ISPIPeripheral>`,
so the radio attaches as its single child. DIO0 (numbered GPIO output 0) wires to
a GPIO input pin:

```
// platforms/cpus/esp32c3.repl already defines:
//   spi2: SPI.ESP32C3_SPI2 @ sysbus 0x60024000
//   gpio: GPIOPort.ESP32C3_GPIO @ sysbus 0x60004000

radio: SPI.SX1278 @ spi2
    0 -> gpio@4          // DIO0 -> GPIO pin 4
```

Include `SX1278.cs` (via the setup `.resc` or `include @...`) before the platform
description that references it. The class lives in
`Antmicro.Renode.Peripherals.SPI` because Renode's `.repl` type resolver only
searches the `Antmicro.Renode.Peripherals.*` namespace tree.

## SPI framing (SX127x)

- First byte of each transaction = **address byte**: bit7 is `wnr`
  (1 = write, 0 = read), bits[6:0] are the 7-bit register address.
- Subsequent bytes are data; the address **auto-increments** per byte (burst).
- MISO during the address byte is undefined (the model returns 0).
- `FinishTransmission()` (chip-select deassert) ends the transaction and resets
  the byte-position state, so the next byte is again an address byte.

## What is modeled

| Item | Behaviour |
|------|-----------|
| Register file | Flat 0x00–0x7F byte array; writes persist and read back. |
| Burst access | Address auto-increments (masked to 7 bits) per data byte. |
| `RegVersion` (0x42) | Reads `0x12` (SX1276/77/78 silicon id); writes ignored (read-only). |
| `RegOpMode` (0x01) | Mode field [2:0] and the rest read back writes. `LongRangeMode` (bit7, LoRa) is only writable while in **SLEEP** mode (datasheet 6.2); otherwise bit7 is retained. |
| Reset map | POR defaults from the SX1276/77/78/79 datasheet (Rev. 7) register table, FSK/OOK page. Reserved registers not in the map reset to `0x00`. |
| DIO0 | Exposed as `INumberedGPIOOutput` (numbered output 0) for later waves; never asserted by this model yet. |

## What is deferred (later wave)

- **RF data path** and the FSK/OOK packet engine (needs the shared 433 MHz air
  medium).
- **RegFifo (0x00)** as a real FIFO queue — currently a plain register byte.
- **DIO0 interrupt generation** (TxDone/RxDone/etc.) — the line is exposed but
  the model never drives it high.
- **RSSI / AFC / PLL / temperature** dynamic behaviour — plain registers only.
- The optional RST GPIO input (`IGPIOReceiver`) — the ESP GPIO model does not yet
  expose per-pin outputs to drive it, so it is not wired. `Reset()` restores POR
  defaults when the machine resets.

## Tests

- Model: `peripherals/sx1278/SX1278.cs`
- Overlay: `peripherals/sx1278/sx1278_tester.repl`
- Firmware: `peripherals/sx1278/firmware/main/test_sx1278.c` (drives SPI2 the way
  the real driver does, printing `[SX1278]` lines)
- Suite: `peripherals/sx1278/test.robot`

```bash
# On desktop.buddy.mithis.com, in ~/renode-espemu-sx1278
source ~/esp/esp-idf/export.sh
idf.py -C peripherals/sx1278/firmware set-target esp32c3
idf.py -C peripherals/sx1278/firmware build

renode-test \
  --variable "BASE:$PWD" \
  --variable "ROM_ELF:$HOME/esp/esp-rom-elfs/esp32c3_rev3_rom.elf" \
  peripherals/sx1278/test.robot
```

The suite asserts `RegVersion == 0x12`, the `RegOpMode` transitions (default,
SLEEP, LoRa enable, LoRa-locked-outside-SLEEP), an ordinary register round-trip,
a burst write/read-back, and `PASSED=9 FAILED=0 TOTAL=9`.
